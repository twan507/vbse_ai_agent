# brand/ — brand asset dùng chung

Logo, palette màu, font, boilerplate disclaimer, thông tin liên hệ (hotline, website) cho bản render branded. Hai nơi tiêu thụ: O pack chế độ branded của `agent_analyst` (weekly_overview, vbse_strategy, stock_report gửi KH) và `agent_marketing`.

Hiện trống. User gửi asset qua chat → AI chuẩn hoá tên rồi lưu vào đây (luồng intake CLAUDE.md mục 2.3). Khi đã có asset, tạo `brand_spec.md` chốt: mã màu, font hierarchy, quy tắc đặt logo, wording disclaimer chuẩn — các engine đọc file đó thay vì hỏi lại branding info mỗi pre-flight.
